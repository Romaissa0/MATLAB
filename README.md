# Numerical Methods in MATLAB

A collection of MATLAB implementations of classical numerical methods developed as part of coursework and independent practice.

## Topics Covered

- Explicit Euler Method
- Implicit Euler Method
- Fourth-Order Runge-Kutta (RK4)
- MATLAB ODE45 Solver
- Van der Pol Oscillator
- Adams-Bashforth 3-Step Method
- Adams-Moulton 3-Step Method
- Predictor-Corrector Methods
- Forward Finite Difference
- Initial Value Problems (IVPs)
- Neumann Boundary Conditions
- Error Analysis
- Surface Visualization using `meshgrid` and `surf`

## Repository Structure

- `ODE-Solvers/`
- `Multi-Step-Methods/`
- `Finite-Difference/`
- `Error-Analysis/`
